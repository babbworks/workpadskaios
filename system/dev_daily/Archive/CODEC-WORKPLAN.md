## Round 1 — Frame Core: meta bytes + field flags + text/date blocks

Replace 1eg/ encoder with pads-v1 (1pa). Binary skeleton every other round plugs into: meta1, meta2, field_flags, field_flags3, field_flags4 passthrough, and data blocks for all text, compact-text, date, and time fields. No financial data. Legacy decode (1eg/ and older) preserved intact.

**Files:** `js/lib/codec.js` (rewritten), `js/screens/share.js` (tag update), `js/screens/management.js` (display string)  
**Spec:** FRAME-SPEC §1 (envelope), §2 (meta1, ext_template, meta2, field_flags, field_flags3, field_flags4), §4 Profiles A + E  
**Test file:** `test/codec-pads-v1.test.js`

### meta1
- [x] META2_PRESENT (bit 7): set when meta2 needed; clear otherwise
- [x] EXT_TEMPLATE (bit 6): routes to ext_template bytes when set; BASE_TEMPLATE in bits 5-3 when clear
- [x] BASE_TEMPLATE bits 5-3: all 8 values (000=Service … 111=Generic) encode and decode correctly
- [x] ACK_REQUEST (bit 2), CHAIN (bit 1), RECIPIENT_TYPE (bit 0) roundtrip
- [ ] EXT_TEMPLATE=1, EXT_SIGNAL=001 (+1 byte): encode → 1 ext byte; decode reads domain-type index
- [ ] EXT_TEMPLATE=1, EXT_SIGNAL=010 (+2 bytes): encode → uint16 BE; decode reads correctly
- [ ] EXT_TEMPLATE=1, EXT_SIGNAL=011 (+3 bytes): encode → 24-bit BE; decode reads correctly
- [ ] EXT_TEMPLATE=1, EXT_SIGNAL=100 (variant, 3 bytes): encode CRC-8(creator_id) + CRC-16(id+name+date); decode returns `_extTemplateId.ns` + `_extTemplateId.id`

### meta2
- [x] meta2 written ONLY when: (COMPACT_TIME=1 AND date/time fields present) OR hasTrigBlock OR domain>0 OR draft OR restrictForward
- [x] COMPACT_TIME (bit 6): written when date/time fields are present
- [x] HAS_TRIG_BLOCK (bit 5) roundtrips
- [ ] PARTICIPANTS (bit 4) roundtrips (encode + decode; block itself is Round 4)
- [ ] SELF_DESCRIBING (bit 7)=1: decoder must NOT crash; returns records with raw block bytes; not generated by encoder in Round 1
- [x] DOMAIN (bits 3-2) roundtrips
- [x] DRAFT (bit 1), RESTRICT_FORWARD (bit 0) roundtrip

### field_flags (2 bytes, always present)
- [x] field_flags written as uint16 big-endian
- [x] FLAGS3_PRESENT (bit 15): set when any FIELDS3 field is present; triggers field_flags3 byte
- [x] All 14 data bits (0–11, 13–14): correct bit is set when field is non-null/non-empty

### field_flags3 (1 byte, if FLAGS3_PRESENT)
- [x] All 7 data bits (0–6) encode correctly when fields are present
- [ ] FLAGS4_PRESENT (bit 7): when set, consume 1 byte from stream on decode; encoder always writes 0 for this bit (Round 8 sets it)

### COMPACT_TIME arithmetic
- [x] Epoch: 2000-01-01 (NOT 2020-01-01 — legacy epoch used in 1eg/ is LEGACY_DATE_EPOCH_MS only)
- [x] dateToDays('2000-01-01') = 0; dateToDays('2000-01-02') = 1; dateToDays('2026-05-17') = 9633
- [x] daysToDate(0) = '2000-01-01'; uint16 range covers to ~2179
- [x] timeToMinutes('09:30') = 570; minutesToTime(570) = '09:30'
- [x] Edge: timeToMinutes('00:00') = 0; timeToMinutes('23:59') = 1439
- [ ] COMPACT_TIME=0 path: date written as [uint16 len][UTF-8 ISO date string] (e.g. '2026-05-17' = 10 bytes + 2 len = 12 bytes)
- [ ] COMPACT_TIME=0 path: time written as [uint16 len][UTF-8 time string] (e.g. '09:30' = 5 bytes + 2 len = 7 bytes)

### Data blocks — encoding rules
- [x] text (standard): [uint16 BE length][UTF-8 bytes] — bits 0-3, 7-11; FLAGS3 bits 4-6
- [x] compact: [uint8 length][UTF-8 bytes] — bits 13, FLAGS3 bits 0-2 (max 255 bytes; truncates silently)
- [x] date (COMPACT_TIME=1): uint16 BE days since 2000-01-01
- [x] time (COMPACT_TIME=1): uint16 BE minutes since midnight
- [x] All blocks written in ascending bit-order of their flag bit; decoder reads in same order
- [x] actions array coerced to '\n'-joined string on encode; decoded as plain string in pads-v1

### Specific field rules
- [x] ref_number (bit 13): compact encoding [uint8 len][UTF-8], max 255 bytes
- [x] due_date (bit 14): date encoding (uint16 days with COMPACT_TIME=1)
- [x] date_end (FLAGS3 bit 3): date encoding (uint16 days with COMPACT_TIME=1)
- [x] financial block (bit 12): encoder leaves bit 12 unset (Round 2 sets it); decoder encountering bit 12 set returns `_financialBlockPending: true` and stops

### Verification profiles
- [x] **Profile E** (10B raw): meta1=0x00, field_flags=[0x00, 0x01], job=[0x00, 0x05, 'Visit'] → exactly 10 bytes before deflate
- [x] **Profile A** (33B raw with meta2): meta1=0x80, meta2=0x40, field_flags=[0x00, 0x05], job=[0x00, 0x19, 25-char string], date=[uint16 days] → exactly 33 bytes before deflate

### URL and routing
- [x] encode() emits `workpads.me/p#1pa/<base64url(deflated)>` — not `1eg/`
- [x] decode() routes: `#1pa/` → parseFrame; `#1eg/` → padsDecodeKaios; `#1ag/` `#1bg/` `#1cg/` `#1dg/` → padsDecodeLegacy; `alg=bitpad-v1` → padsDecodeLegacy text mode

## Round 2 — Financial Block: amounts, tax, scaling, I>O states

Add the money layer. Encoder sets BASE_TEMPLATE=001 (Financial) when financial opts present. Inserts setup_byte, optional currency_ext, optional sf_byte, transaction_byte (DOMAIN=01 I>O), fin_control, customer_amount (uint24), worker_amount, tax_block, qty_rate_block. Profiles B, C, D from §4 must produce exact byte counts.

**Files:** `js/lib/codec.js`  
**Spec:** FRAME-SPEC §2 (financial context through financial block), §3 (I>O subtype table), §4 Profiles B–D, §17 (DOMAIN=11 groundwork)  
**Test file:** `test/codec-pads-v1.test.js` (add financial section)

### setup_byte (1 byte, when DOMAIN ≥ 01)
- [x] DECIMAL_POS bits 7-5: all 8 values (000–111) encode/decode; 111=flat uint24 mode (raw smallest-unit integers, no scaling)
- [x] CURRENCY bits 4-3: 00=home, 01=first common, 10=second common, 11=extended (currency_ext follows)
- [x] TAX_CODE bits 2-1: 00=none, 01=inclusive (tax_block required), 10=exclusive (tax_block required), 11=compound (post-MVP, encode only)
- [x] SF_PRESENT (bit 0): 0=SF=×1 default; 1=sf_byte follows

### currency_ext (1 byte, if CURRENCY=11)
- [x] uint8 code 0x01–0xFE: 254 currency slots; full table in OQ-3 (OPEN-QUESTIONS.md)
- [ ] 0xFF reserved: encoder must reject, decoder must signal error (not tested — deferred)
- [x] currency_ext absent when CURRENCY≠11

### sf_byte (1 byte, if SF_PRESENT=1)
- [x] SCALING_FACTOR bits 7-5: all 8 values (000=×1, 001=×10, 010=×100 … 111=×1,000,000,000) decode to correct multiplier
- [ ] COMPOUND_VALUE (bit 4): 1=compound block follows financial block (Round 6 sets this)
- [x] QTY_COMPACT (bit 3): 0=separate qty+rate fields, 1=packed into customer_amount uint24
- [x] SPLIT_POINT bits 2-0: 0=default 8-qty-bits; 1–7=exactly that many bits to qty
- [ ] SPLIT_POINT table verified for non-zero SP values: SP=7 → qty max 127, rate max 131071 (deferred)

### transaction_byte (1 byte, when setup_byte present; absent for State Commit)
- [x] DOMAIN=01: DIRECTION (bit 7), TIME (bit 6), EFFECT (bit 5) — all 8 I>O states encode as correct byte (6 of 8 explicitly tested; all combinations verified by formula)
- [x] DOMAIN=01: SUBTYPE bits 4-3 — subtype 00/01 tested; all 4 values per I>O roundtrip
- [x] DOMAIN=01: QTY_SPLIT (bit 2) — 1=quantity+rate encoding active
- [x] DOMAIN=01: ROUNDING bits 1-0 — 00=exact tested; 01=NEVER SET (encoder passes value through; guard deferred to Round 8)
- [x] Common records match spec §3 table: payment received = 0x00, invoice sent = 0x40, quote = 0x48, parts paid = 0xB0 (0xA0 without sub — tested)
- [ ] DOMAIN=10 (Round 3): ACCOUNT_PAIR bits 7-4, DIRECTION (bit 3), STATUS (bit 2), QTY_SPLIT (bit 1), ROUNDING (bit 0)

### fin_control (1 byte, DOMAIN=01)
- [x] BILLED (bit 7): 1=charge passed to customer; EXPENSE_CAT=00 forces BILLED=1 (business rule; encoder enforces on O-direction)
- [x] bit 6: must always be 0 (mode indicator; decoder integrity check 1)
- [x] QTY_TYPE (bit 5): 0=units/items, 1=time/hours
- [x] PARITY (bit 4): even parity of bits 7, 5, 3, 2, 1, 0; encoder calculates and sets; decoder verifies
- [x] EXPENSE_CAT bits 3-2: 00=job charge, 01=job cost/COGS, 10=running cost, 11=RESERVED (decoder throws)
- [x] CUSTOMER_AMT (bit 1): 1=customer_amount uint24 follows
- [x] WORKER_AMT (bit 0): 1=worker_amount uint24 follows
- [x] Four integrity checks verified on decode: (1) bit6=0, (2) PARITY correct, (3) EXPENSE_CAT≠11, (4) implicit (QTY_TYPE cross-check deferred)

### fin_control (1 byte, DOMAIN=10)
- [ ] BILLED (bit 7): same semantics (Round 3)
- [ ] bit 6: must always be 1 (mode indicator; decoder integrity check) (Round 3)
- [ ] ACCOUNT_PAIR bits 5-2: 4-bit BitLedger Account Pair (Round 3)
- [ ] CUSTOMER_AMT (bit 1), WORKER_AMT (bit 0): same (Round 3)

### Amounts: customer_amount and worker_amount
- [x] Simple total (QTY_COMPACT=0, QTY_SPLIT=0): uint24 BE, real value = (uint24 × SF) / 10^DECIMAL_POS
- [x] Packed qty+rate (QTY_COMPACT=1, QTY_SPLIT=1): qty = uint24 & mask, rate = uint24 >> SP; real = (rate × qty × SF) / 10^DECIMAL_POS
- [x] Separate qty+rate fields (QTY_COMPACT=0, QTY_SPLIT=1): customer_amount = total; qty_rate_block follows (6B)
- [ ] QTY_TIME mode: when qty_unit (FLAGS3 bit 2) is a time unit AND QTY_TYPE=1: qty encoded as [uint8 hours][uint8 minutes_index] (deferred — Round 8)
- [x] DECIMAL_POS=111 (flat): amounts stored as raw smallest-unit integers; no scaling on decode (via amountToU24 dp=7 path)
- [x] worker_amount NOT present in customer-facing view (internal cost field — only in record._fin or record.worker_amount)

### tax_block (3 bytes, if TAX_CODE=01 or 10)
- [x] byte 1: uint8 tax rate in permille (e.g. 200 = 20.0%)
- [x] bytes 2-3: uint16 tax amount; SF and DECIMAL_POS apply
- [x] tax_block absent when TAX_CODE=00

### qty_rate_block (6 bytes, if QTY_SPLIT=1 AND QTY_COMPACT=0)
- [x] bytes 1-3: uint24 quantity; SF and DECIMAL_POS apply
- [x] bytes 4-6: uint24 rate per unit; SF and DECIMAL_POS apply
- [x] customer_amount remains the authoritative total (qty × rate ≈ customer_amount, within rounding)

### BASE_TEMPLATE auto-selection
- [x] When financial opts present: BASE_TEMPLATE auto-set to 001 (Financial)
- [ ] When compound opts present (Round 6): BASE_TEMPLATE auto-set to 010 (Compound financial)

### Verification profiles
- [x] **Profile B** (36B raw): meta1=0x88, meta2=0x44, setup=0x40, tx=0x00, field_flags=0x1007, job (13B text), customer (7B text), date (2B), fin_control=0x12, customer_amount=12550 (£125.50) → exactly 36 bytes  
  _Note: FRAME-SPEC v1.0.1 corrected meta2 from 0x42→0x44 (DOMAIN bits 3-2, not 2-1)_
- [x] **Profile C** (36B raw): meta1=0x88, meta2=0x44, setup=0x41, sf=0x08, tx=0x44, field_flags=0x1007, job (11B), customer (8B), date (2B), fin_control=0x22, customer_amount packed (3B) → exactly 36B

- [x] **Profile D** (76B raw): as Profile B with meta2=0x54 (PARTICIPANTS=1, DOMAIN=01), participants block 37B → exactly 76 bytes

## Round 7 — Security Wrapper

Five-layer security stack applied outside the pads-v1 frame before base64url. New `js/lib/security.js`. AES-CTR 128-bit, field scramble, deflate seed poisoning, HMAC tag, preamble byte. `#1ps/` full scramble and `#1ph/` partial scramble URL round-trips.

**Files:** `js/lib/security.js` (new), `js/lib/codec.js` (integrate wrapper in encode/decode routing), `js/services/PersonalService.js`  
**Spec:** FRAME-SPEC §12 (§12.1–§12.3), TAG-REFERENCE.md, draft_specs/SECURITY-DESIGN.md

- [x] Key derivation: `master = SHA-256(passphrase || salt)` (32 bytes); `cipher_key = master[0:16]`; `scramble_seed = master[16:32]`; `iv = master[0:16]`
- [x] Random salt: 4 bytes generated fresh per record; two records with same passphrase get different IVs (salt freshness guarantees)
- [x] AES-CTR 128-bit encrypt/decrypt roundtrips correctly using cipher_key and iv
- [x] Field scramble: Fisher-Yates byte shuffle of compressed bytes using scramble_seed[4:8]; unshuffle restores original ordering
- [x] Deflate seed poisoning: XOR first 256 bytes of frame with LCG mask from scramble_seed[0:4] before deflate; un-XOR after inflate to recover original
- [x] HMAC-SHA256 tag (8B truncated): keyed on `cipher_key || receiver_phone_hash`; embedded as last 8 bytes INSIDE encrypted envelope; verified after decrypt; wrong key → HMAC mismatch → reject
- [x] Preamble byte: SCRAMBLE (bit 7), AES (bit 6), HMAC (bit 5), SEED_POISON (bit 4), HKDF_KEY (bit 3), KEY_HINT bits 2-0 (lower 3 bits of cipher_key[0])
- [x] KEY_HINT check on decode: `cipher_key[0] & 0x07` must match preamble bits 2-0; mismatch → abort before full decrypt
- [ ] HMAC=1 requires RECIPIENT_TYPE=1 in meta1 — encoder enforcement deferred (app layer)
