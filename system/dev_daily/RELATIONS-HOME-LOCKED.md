# Relations home lens (C16 / B3) — locked
_2026-05-24. WP+ home alternate when `relations_home` UI phase flag is on._

---

## Enable

Manage → App → **Focused round: needs/offers home** (`relations_home`).

Boot WP+ home (`wp_home_mode` = `wp+`) with flag on → Relations lens instead of WORK/PADS grid.

Disable: key **0** on lens footer (“Classic WP+ home”) or toggle off in Manage.

---

## Layout

| Zone | Keys |
|------|------|

| Top rhythm contacts | Enter on row → contact view |
| + Need / + Offer / Classic | **4** / **5** / **0** |
| All records | SoftRight → classic list |
